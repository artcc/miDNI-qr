Demo app in SwiftUI that scans the binary payload of a QR code (using the camera), sends it to a backend for verification, and renders the decoded data or an error state. It is intended to scan the QR generated by the official miDNI app (CNP) and display validated data returned by the backend.

## Features
- Live QR scanning with the front camera
- Extracts the binary QR payload (not text) for verification
- POST request to a backend endpoint with bearer auth
- Shows decoded document fields and thumbnail image
- Error and retry flow

## Requirements
- Xcode 15 or newer
- iOS 17 or newer
- A device with a camera (simulator does not support QR camera scanning)

## Getting started
1. Open the Xcode project: `miDNI-qr.xcodeproj`.
2. Select a physical iPhone as the run destination.
3. Ensure camera permissions are granted when prompted.

## Backend configuration
Backend settings live in `BackendConfig.swift`:

- `baseURLString`: Base URL for the backend API
- `bearerToken`: Authorization token for the `Authorization: Bearer` header

The app expects the backend to expose `POST /verify` with a JSON body:

```json
{
  "payloadBytes": [1, 2, 3]
}
```

The response is decoded into `VerifyResponse` and shown in the UI.

## How it works
- `ScannerView` embeds an `AVCaptureSession` preview and drives `QRScannerController`.
- The controller extracts the QR binary payload using `CIQRCodeDescriptor.errorCorrectedPayload`.
- `MainViewModel` sends the payload bytes to the backend and updates UI state.
- `ResponseView` renders fields and an optional thumbnail image.

## Privacy
The camera is used only for QR scanning. Payloads are sent to the configured backend for verification. No data is stored locally by the app.

## Project structure
- `app.swift`: App entry point
- `MainView.swift`: Root UI state routing
- `MainViewModel.swift`: Scan and networking logic
- `ScannerView.swift` / `QRScannerController.swift`: Camera and QR extraction
- `VerifyRequest.swift` / `VerifyResponse.swift`: API models
- `ResponseView.swift`: Result display
